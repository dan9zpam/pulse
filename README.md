# Pulse

Локальное приложение для строки меню macOS, настроенное и проверенное на MacBook Air M2 (Mac14,2), macOS 27.0.1.

## Использование

Откройте `~/Applications/Pulse.app`. В строке меню появится значок пульса и средняя температура доступных датчиков CPU. Нажатие открывает панель мониторинга; правый клик открывает меню выхода. Приложение работает без значка в Dock.

Панель открывается на экране со значком Pulse и ограничивается его рабочей областью. Длинное содержимое, включая раскрытые датчики, прокручивается внутри окна. При изменении конфигурации мониторов открытая панель закрывается; следующее открытие пересчитывает размер и положение.

В панели: температура CPU и GPU, максимальная температура среди датчиков чипа, загрузка CPU/GPU, используемая память и её нагрузка, swap, скорость сети, свободное место, батарея. «Датчики» раскрывает отдельные показания. Шестерёнка позволяет добавить CPU в строку меню, выбрать интервал 2/3/5 секунд и включить запуск при входе. Автозапуск изначально выключен.

История графиков: 60 замеров, заполняется с момента запуска. При стандартном интервале это две минуты. Средняя температура CPU считается только по отвечающим датчикам CPU; перечень доступен в панели. Показатель тепловой нагрузки поступает отдельно от macOS через ProcessInfo.thermalState: он не определяется только градусами. Память: активная + неактивная + спекулятивная + wired + физически сжатая − purgeable − файловая. Swap показывается отдельно. Сеть: суммарные скорости физических интерфейсов en*, без повторного учёта туннелей VPN. Свободное место: системная оценка свободных блоков тома домашнего каталога, без обещания очистить purgeable.

Температуры считываются через AppleSMC, GPU через IOKit, остальные показатели через системные API. Нет sudo, фоновых shell-команд, сетевых запросов, телеметрии и зависимостей Swift Package Manager. Приложение только читает датчики. У Air M2 нет вентиляторов.

## Сборка

Нужны Command Line Tools с Swift и macOS SDK:

```sh
cd ~/Projects/Pulse
./build.sh
```

Результат: `build/Pulse.app`. Локальная ad-hoc подпись, без notarization. Для распространения другим пользователям потребуется отдельная подпись и проверка на их Mac. Поддержка датчиков других моделей не заявлена: ключи настроены для M2. Приватный AppleSMC API может измениться в будущих macOS; недоступный датчик отображается прочерком.

Проверка реальных показаний без запуска интерфейса:

```sh
./build/Pulse.app/Contents/MacOS/Pulse --diagnose
```

JSON содержит фактические показания; если температура недоступна, поле отсутствует. `--preview` открывает отдельное окно и сохраняет изображение панели в `preview.png` через 6 секунд; `--show` сразу раскрывает панель строки меню.

Для обновления установленного приложения завершите Pulse, скопируйте `build/Pulse.app` в `~/Applications/` и запустите. Приложение удаляется обычным перемещением в Корзину; включённый автозапуск предварительно выключите в настройках Pulse.

## Проверка размещения окна

`--test-layout` проверяет 24 положения окна в четырёх конфигурациях экрана. `--check-layout` открывает настоящую панель и проверяет её границы на каждом подключённом экране; затем завершает приложение. Добавьте `--expanded-sensors`, чтобы проверить раскрытый список датчиков. Снимок последней панели сохраняется в `layout-check.png`.
